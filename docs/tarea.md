# 🚀 Portafolio Personal - Especificaciones de Desarrollo

> **Objetivo Principal:** Crear una página web tipo portafolio que muestre de manera profesional y atractiva quién soy, mis habilidades, proyectos y formas de contacto.

---

## 📄 Estructura de la Página

La página estará compuesta por **6 secciones principales**, cada una con un propósito específico:

### 🎯 **Sección 1 - Hero**

- **Presentación impactante** con nombre, título profesional y lema personal
- **Botón CTA principal** para ver proyectos o descargar CV
- **Imagen/ilustración de fondo** siguiendo el sistema visual establecido

### 👨‍💻 **Sección 2 - Sobre Mí**

- **Descripción personal:** trayectoria, especialidades y valores
- **Stack tecnológico:** herramientas y tecnologías que domino
- **Experiencia profesional:** años de experiencia y enfoque actual

### 🎨 **Sección 3 - Proyectos Destacados**

- **Galería visual** de proyectos con miniaturas atractivas
- **Modales interactivos** para cada proyecto que incluyan:
- ✨ Nombre del proyecto
- 📝 Descripción detallada
- 🛠️ Stack tecnológico utilizado
- 🖼️ Imagen o video demo
- 🔗 Enlaces a repositorio y demo en vivo (puede no estar disponible)

### 💼 **Sección 4 - Servicios / Qué Ofrezco**

- **Descripción de servicios** como freelancer/colaborador/consultor
- **Lista de especialidades:**
- 🎨 Diseño de interfaces (UI/UX)
- 💻 Desarrollo full stack
- 🤝 Asesorías técnicas
- 📱 Desarrollo de aplicaciones

### 💬 **Sección 5 - Testimonios / Clientes**

- **Comentarios destacados** de clientes y colaboradores
- **Modales expandidos** con testimonios completos que incluyan:
- 👤 Foto del cliente
- 💼 Rol y empresa
- 📝 Testimonio completo

### 📞 **Sección 6 - Contacto**

- **Formulario funcional** de contacto
- **Enlaces a redes sociales** (LinkedIn, GitHub, Twitter, etc.)
- **Opciones de comunicación:** agendar llamada o envío directo de email

---

## 🖼️ Interacciones y UX

### **Modales Interactivos**

Todos los elementos expandibles (proyectos, testimonios, detalles) se abrirán en modales con:

- ✅ **Información visual clara** y bien estructurada
- 🎨 **Excelente contraste** y tipografía legible
- ❌ **Botón de cierre** visible y accesible
- � **Diseño responsive** para todos los dispositivos

### **Animaciones y Transiciones**

- 🌊 Transiciones suaves entre secciones
- ✨ Efectos hover en elementos interactivos
- 📈 Animaciones de entrada progresiva (scroll-triggered)
- Usa Aceternity UI para elementos graficos que puedan dar un aspecto moderno a la web

---

## 🛠️ Stack Tecnológico

### **Framework Principal**

### **Framework:** Astro con TypeScript

### **Componentes:** React para interactividad

### **Estilos:** Tailwind CSS

### **Animaciones:** Framer Motion + Aceternity UI

### **Build:** `astro build` → estático en /dist
